# Python Turtle Patterns

A Python Turtle demo that draws overlapping circles, squares, and triangles by rotating each repeated shape 36 degrees.

## Setup

Use Python 3 with Tkinter and a graphical desktop. You can check that Tkinter works with `python -m tkinter`. The demo uses the standard library and needs no pip packages.

## Run

From the repository folder, run `python screen.py`. Use `python3 screen.py` if that is your Python 3 command.

## Example

The script opens a black window and draws three red patterns. Click the drawing window after the patterns appear to close it.
